# DesktopBoxes 隐私政策

**生效日期：2026年9月25日**

## 概述

DesktopBoxes（以下简称"本应用"）由个人开发者胡行东（以下简称"开发者"）开发和发布。本隐私政策旨在说明本应用如何处理您的信息。

## 我们收集的信息

**本应用不收集任何个人信息。**

DesktopBoxes 是一款本地桌面工具软件，所有功能均在您的设备本地完成。本应用不会：

- 收集您的姓名、邮箱、电话号码等个人身份信息
- 收集您的设备标识符、位置信息或使用行为数据
- 将任何数据传输到开发者或第三方的服务器
- 使用 Cookie 或类似技术追踪您的活动

## 文件与数据的处理

本应用在运行过程中可能会访问您设备上的文件或文件夹，以完成您主动发起的操作（如整理、管理桌面项目等）。这些文件：

- **仅在您的本地设备上被读取和处理**
- **不会被上传、复制或传输到任何外部服务器**
- **不会被开发者或任何第三方访问**

当您卸载本应用后，应用产生的本地配置数据将随之被清除。

## 第三方服务

本应用不集成任何第三方分析、广告或数据收集服务。

## 儿童隐私

本应用不针对儿童设计，也不会有意收集儿童的任何信息。由于本应用不收集任何用户数据，因此不存在此类风险。

## 您的权利

由于本应用不收集任何个人数据，因此不涉及数据访问、更正、删除或导出等请求。您可以随时通过卸载本应用来清除所有本地数据。

## 隐私政策的变更

如果本隐私政策发生变更，开发者会在本页面更新内容并修订生效日期。建议您定期查看本页面以了解最新信息。
